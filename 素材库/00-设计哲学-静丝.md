## 哲学

**静丝**相信：最深的静不是空白，而是**一根线被无限延长时的那种感觉**——有方向，有张力，有将落未落。它拒绝把「安静」误读为「冷淡」，也拒绝把「精致」误解为「堆砌」。静丝的一切，都从一次呼吸开始。

**空间**是静丝的第一材料。它大面积地留白，留白不是没做完，而是让观看本身成为内容。留白必须**有方向**——或向上（让视线升起，进入叙事），或向内（让视线收拢，回到一枚针尖）。静丝从不用对称的空洞来充数；空也必须有张力，像弓弦松开前的那一刻。

**材质**只有四种：丝、纸、墨、朱。它们各自被严格限制：**丝**负责纵深（层层叠叠的细线，光在其间流动）；**纸**负责温度（吸光的暖白，让深色有底）；**墨**负责呼吸（低对比的晕，永远不越过中灰）；**朱**负责一次心跳（整幅画里只允许一次，用完即止）。金不是第五种材质，金是丝的另一种状态——只在最需要被看见的线上出现。

**颜色**是克制的秩序：藏青为夜，描金为光，铜为影，米为昼，朱为印。静丝不使用纯白作为大面积背景，也不使用纯黑作为大面积背景——纸有纸的黑，绢有绢的黑，夜晚是藏青而非墨黑。**明度差永远不超过一档**，让画面靠质地而非对比说话。

**节奏**遵循「密—疏—密」。信息密集处像绣面，针脚密到几乎看不清；留白处像未绣的底料，一根线都没有。任何一次视觉冲击之后，必须有一次近乎空白的停顿，让眼睛重新校准焦距。静丝不追求第一眼惊艳，追求的是**看第三眼时开始觉得舒服**。

**工艺**是静丝的信仰。这些素材没有一张是「做出来」的，都是**一针一针绣出来的**。每一根丝线的粗细、每一次晕染的边缘、每一处噪点的密度，都必须经得起把图片放大到 400% 之后的审视——因为真正的手工艺，是骗不过近距离的。留白处也要有手工的痕迹：纸纹、手工的印章边缘、绢的经纬。

**留字如留白。** 静丝的文字只是必要的坐标：极小的等宽标注贴在角落，像标本的编号，而不是解说。若必须出现字，用极细的衬线体；若有印，印是唯一允许方正且浓烈的元素，其余一律退后。

## 运用范围

本套素材用于：网站背景层、章节过渡、占位图底纹、装饰性印章、线稿图形。

**它不用于**：商品主图、人物肖像、以及任何需要代表真实商品的场合。
静丝是**氛围**，不是**证据**。证据必须由实拍承担。

## 技术约束

| 项 | 规定 |
|---|---|
| 纹理线宽 | ≥ 0.5px；低于此值在高分屏会消失 |
| 纹理密度 | 每 100px² 不超过 3 条主线，避免摩尔纹 |
| 噪点 | opacity ≤ 0.025（纸）/ ≤ 0.05（绢） |
| 晕染对比 | 最低明度不低于底色的 82% |
| 印章 | 朱砂 `#A8352A`，边缘须有手工残缺（缺口 ≥ 3 处） |
| 矢量 | SVG 一律内联或外链，不转位图 |
| 动画 | 仅线性与正弦，无缓动曲线（丝线不加速） |
| 降级 | 所有动效在 `prefers-reduced-motion` 下静止 |
